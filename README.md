# Bitwarden

## Descrição

O Bitwarden é um gerenciador de senhas...

## Público-alvo

- Usuários comuns
- Empresas
- Equipes de desenvolvimento

## Funcionalidades

- Armazenar senhas
- Gerar senhas fortes
- Preencher senhas automaticamente
- Sincronizar dados entre dispositivos

## Tecnologias utilizadas

- C#
- .NET
- TypeScript
- Angular
- Rust
- SQL Server
- Docker


## Requisitos técnicos

- Sistema operacional: Windows 10/11, macOS ou Linux.
- Processador: 64 bits, com no mínimo 2 núcleos.
- Memória RAM: mínimo de 4 GB, recomendado 8 GB ou mais.
- Armazenamento: pelo menos 2 GB disponíveis para instalação e dependências.
- Ambiente de desenvolvimento: .NET SDK, Node.js e npm.
- Backend: C# e .NET.
- Frontend: TypeScript e Angular.
- Banco de dados: Microsoft SQL Server.
- Criptografia: utilização de criptografia para proteção das credenciais e dados armazenados.
- Containers: Docker para execução e gerenciamento dos serviços.
- Rust: necessário para componentes que utilizam funcionalidades desenvolvidas em Rust.
- Navegador: Chrome, Edge, Firefox, Safari ou outro navegador moderno compatível.
- Conexão com a internet: necessária para sincronização dos dados entre dispositivos e acesso aos serviços.
- Segurança: senhas e informações sensíveis devem ser armazenadas de forma criptografada, utilizando mecanismos de autenticação e proteção de dados.
- Controle de versão: Git para gerenciamento do código-fonte e colaboração entre os desenvolvedores.
- Dependências: todas as bibliotecas e frameworks necessários devem estar nas versões compatíveis especificadas pelo projeto.
